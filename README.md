## Project Overview

This project is a responsive website built for a local Pick n Pay branch, designed to give the community an easy way to learn about the branch, its services, and how to find and contact it. The site follows Pick n Pay's brand identity (dark blue and cherry red) and focuses on clarity, accessibility, and ease of navigation across devices.

## Website Goals and Objectives

- Increase awareness of the branch's location, trading hours, and in-store services
- Drive foot traffic and online enquiries from the surrounding community
- Promote weekly specials and the Smart Shopper loyalty programme
- Provide a simple, accessible way for customers to submit enquiries

## Key Features and Functionality

- Fully responsive design (desktop, tablet, mobile)
- Home page with hero banner and welcome introduction
- About page detailing history, mission, vision, and team
- Services page showcasing departments (fresh produce, bakery, pharmacy, Smart Shopper)
- Enquiry page with a working contact form
- Contact page featuring two branch locations, trading hours, and an embedded map
- Consistent navigation menu across all pages, with a mobile menu toggle
- Interactive styling (hover, focus, and active states) on buttons, links, and cards

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (mobile navigation toggle)

## Responsiveness

The website adapts across three breakpoints:
- *Desktop* (default) – multi-column layouts, full navigation
- *Tablet* (max-width: 1024px) – 2-column service grid, adjusted spacing
- *Mobile* (max-width: 700px / 600px) – single-column layout, collapsible nav menu, resized typography

Tested using browser developer tools across desktop, tablet, and mobile viewport sizes.

## How to Run the Website

1. Download or clone the project repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Use the navigation menu to move between pages.
